# GHowe 串口调试助手 (GHowe Serial Tool)

这是一个功能丰富的串口调试工具, 基于 PyQt5 构建, 旨在为嵌入式开发和硬件调试提供一个强大, 灵活且易于使用的界面.

## 主要功能

- **完整的串口配置**: 支持所有标准配置, 包括端口, 波特率, 数据位, 校验位和停止位.
- **实时数据收发**: 
    - 在独立线程中处理串口通信, 确保 UI 界面流畅.
    - 实时显示发送和接收的数据, 支持 **暂停/恢复** 显示.
    - 优化的数据显示逻辑, 智能处理换行符和时间戳, 确保接收区整洁.
- **命令序列与模板**:
    - 支持创建, 编辑和发送多条命令.
    - 可将命令序列保存为模板 (`.csv` 或 `.txt`) 并随时导入, 方便复用.
    - 支持通过 `mode:` 指令对命令进行模块化分组.
- **连续发送与循环发送**:
    - 可按设定时间间隔自动连续发送选中的命令.
    - 支持 **循环发送** 模式, 在一轮发送完成后自动等待设定的循环间隔并重新开始.
- **自动保存与恢复**:
    - 程序关闭时自动保存所有状态, 包括命令列表 (含勾选, 内容, 注释), 串口配置, 发送设置及界面布局.
    - 下次启动时自动恢复到上次离开时的环境.
- **增强的 UI 体验**:
    - **快速命令面板**: 方便常用指令的一键发送.
    - **日志面板**: 完善的日志记录功能, 便于追踪调试过程.
    - **输出来源过滤**: 支持分类显示发送、接收、系统或错误日志，保持接收区清晰。
    - **批量操作**: 支持多行选中同步勾选、批量插入多行及批量删除。
    - **可折叠布局**: 采用可折叠容器设计, 用户可根据需要自定义界面展示.
    - **便捷操作**: 在命令编辑框中按下 **Enter (回车)** 键即可立即发送该行指令；支持 `Ctrl+H` 快捷键唤醒位计算器。
- **特殊指令支持**:
    - `delay:[ms]`: 在命令序列中插入非阻塞延迟.
    - `mode:[name]`: 定义新的命令模块, 用于组织管理.
    - `SendHex:[hex]`: 发送十六进制原始字节数据，支持实时格式化。
    - `BaudRate:[baud]`: 动态切换当前串口波特率。
    - `SetEndlog:[ending]`: 动态修改发送结尾标识符 (None, \r\n, \r, \n)。
    - `SendMode:[module]`: 触发跳转到指定模块进行单次发送。
- **外部工具集成**:
    - 支持集成外部工具 (如 **数字进制转换器**).
    - 在接收区或命令输入框右键点击, 可快速启动转换器进行 HEX/DEC 计算.

## 配置文件

项目使用 `main_config.json` 进行配置管理, 支持自定义:
- 窗口标题
- 默认波特率
- 界面主题
- 外部工具路径
- 历史命令与状态

## 如何运行

该工具被设计为一个 Python 包. 可以通过以下命令从项目根目录启动:

```bash
# 使用 python 模块方式运行 (推荐)
python -m serial_tool_project.main
```

## 外部工具依赖

**配置方式:**
1. 点击主界面左下角的 **"配置"** 按钮.
2. 在弹出的对话框中, 勾选对应的工具并点击 **"浏览..."** 选择工具的可执行文件 (`.exe`) 或脚本文件 (`.py`).
3. 保存配置后, 即可在右键菜单中使用相关功能.

## 文件结构

- `main.py`: 应用程序主入口.
- `main_window.py`: 主窗口 UI 布局和核心逻辑.
- `main_config.json`: 应用程序配置文件.
- `/core`: 核心功能模块 (如串口通信线程).
- `/managers`: 功能管理模块 (配置管理, 输出管理, 指令管理等).
- `/widgets`: 自定义 UI 控件 (基础面板, 命令表格, 折叠容器等).
- `/utils`: 辅助工具和 UI 样式定义.
- `/dialogs`: 各种交互对话框.
- `/resources`: 图标等资源文件.
