# GHowe 串口调试助手 GUI 操作手册

本文档说明图形界面的日常操作、快捷键、查找与替换发送，以及发送编辑区支持的特殊命令。

## 1. 快速开始

1. 在左侧“基础设置”中选择串口和通信参数。
2. 点击“打开串口”，或按 `Ctrl+O`。
3. 在右侧发送编辑区新增或编辑命令。
4. 点击命令行的发送按钮发送单条命令。
5. 需要批量发送时，勾选命令行并使用“连续发送”。
6. 按 `F1` 可随时打开本手册。

## 2. 界面区域

- **基础设置**：串口、波特率、数据位、校验位和停止位。
- **远程控制**：在主控端和远程端之间共享串口数据与控制。
- **接收设置**：控制输出来源、保存接收数据和清空显示。
- **发送设置**：结尾标识符、发送显示颜色、替换发送和发送间隔。
- **发送编辑区**：编辑多条命令、备注、模块和独立替换规则。
- **模板相关**：导入或导出命令模板。
- **工具相关**：打开已启用的转换器和辅助工具。
- **帮助与配置**：`?` 打开帮助，“配置”打开程序配置。

## 3. 快捷键

帮助类快捷键使用功能键，功能操作使用 `Ctrl+字母`。

| 快捷键 | 功能 |
| --- | --- |
| `F1` | 打开帮助窗口 |
| `Ctrl+O` | 打开或关闭串口 |
| `Ctrl+R` | 开始或停止连续发送 |
| `Ctrl+F` | 打开当前区域的查找栏 |
| `Ctrl+T` | 开启或关闭替换发送模式 |
| `Ctrl+H` | 将当前选中文本发送到转换工具 |
| `Enter` | 在发送命令编辑状态下发送当前行 |
| `Ctrl+Z` | 撤销编辑 |
| `Ctrl+Y` | 重做编辑 |
| `Ctrl+X` | 剪切 |
| `Ctrl+C` | 复制 |
| `Ctrl+V` | 粘贴 |
| `Ctrl+A` | 全选当前编辑内容 |

`Ctrl+F` 会根据当前焦点选择查找目标：焦点在接收区时查找接收文本，焦点在发送编辑区时查找发送命令。

## 4. 串口操作

### 4.1 打开与关闭

- 点击“打开串口”或按 `Ctrl+O` 建立连接。
- 连接成功后按钮显示“关闭串口”。
- 再次点击或按 `Ctrl+O` 关闭连接。
- 如果正在连续发送，关闭串口会先停止连续发送。

### 4.2 结尾标识符

“发送设置”中的结尾标识符会追加到普通字符串命令末尾。

| 选项 | 实际追加内容 |
| --- | --- |
| `None` | 不追加 |
| `\r\n` | 回车加换行 |
| `\r` | 回车 |
| `\n` | 换行 |

## 5. 查找

### 5.1 接收区查找

1. 点击接收显示区。
2. 按 `Ctrl+F`。
3. 输入查找内容。
4. 按 `Enter` 查找下一个，按 `Shift+Enter` 查找上一个。

匹配内容会以黄色背景、黑色文字高亮。查找不会把输入焦点强制切换到接收内容。

### 5.2 发送编辑区查找

1. 点击任意发送命令编辑区。
2. 按 `Ctrl+F`。
3. 选择查找范围：当前模块或全部命令。
4. 输入内容并连续按 `Enter` 浏览匹配项。

匹配文本只进行高亮，不会进入命令编辑选中状态，因此可以持续按 `Enter` 查找下一项。

### 5.3 查找选项

- **区分大小写**：大小写必须完全相同。
- **正则表达式**：按正则语法解释查找内容。
- **全字符匹配**：只匹配完整单词或完整字符边界。
- **范围**：发送区可限定当前模块或全部命令。

正则表达式无效时，查找栏会提示错误，不会修改命令内容。

## 6. 替换发送

替换发送只在数据发出的瞬间生成临时发送内容，发送编辑区中的原始字符串保持不变。

### 6.1 全局替换规则

1. 在“发送设置”中点击“全局规则...”。
2. 输入查找内容和替换内容。
3. 根据需要设置区分大小写、正则表达式和全字符匹配。
4. 勾选“替换发送”，或按 `Ctrl+T`。

默认全局规则会把 `write <通道> <地址> <值>` 转为 `read <通道> <地址> 1`。例如 `write 1 0x20 abcd` 会在发送时临时替换为 `read 1 0x20 1`。

### 6.2 命令行独立规则

1. 在发送编辑区选中一行或多行。
2. 右键打开菜单。
3. 选择“设置选中行规则”。
4. 输入所选命令行使用的替换规则。

拥有独立规则的命令行会显示独立的 UI 标记。独立规则优先于全局规则。选择“清除选中行规则”可以移除所选行的独立规则。

### 6.3 是否可替换

程序使用与查找功能相同的匹配逻辑判断命令是否可替换：

- 能查找到匹配内容时，发送按钮进入可替换提示状态。
- 找不到匹配内容时，发送按钮保持普通状态。
- 连续发送中，能匹配的命令发送替换后内容；不能匹配的命令直接发送原始内容。

### 6.4 正则分组替换

开启正则表达式后，可以在查找内容中使用圆括号定义捕获组，并在替换内容中引用。

| 替换写法 | 含义 |
| --- | --- |
| `$1` | 第 1 个捕获组 |
| `${1}` | 第 1 个捕获组的明确写法 |
| `$2` | 第 2 个捕获组 |
| `$&` | 本次匹配到的完整文本 |
| `$$` | 字面量 `$` |

示例：

- 查找：`AT\+(\w+)=(\d+)`
- 替换：`CMD:$1,VALUE:$2`
- 原始命令：`AT+MODE=3`
- 实际发送：`CMD:MODE,VALUE:3`

### 6.5 按钮颜色

- 替换发送模式下，可替换的单条发送按钮使用紫色背景和白色文字。
- “全局规则...”按钮使用紫色背景和白色文字。
- 替换模式下的连续发送按钮使用紫色背景和白色文字。
- 普通连续发送运行状态使用橙色提示。

## 7. 连续发送与循环发送

### 7.1 连续发送

1. 勾选需要执行的命令行。
2. 在“连续发送模块”中选择“全部”或指定模块。
3. 设置“连续发送间隔(ms)”。
4. 点击“连续发送”，或按 `Ctrl+R`。
5. 再次点击或按 `Ctrl+R` 停止。

连续发送会在一次发送单元内完成查找、替换判断和实际发送，不会另外修改命令内容。

### 7.2 循环发送

勾选“循环发送(ms)”后，一轮连续发送结束会等待设定间隔，再开始下一轮。

## 8. 命令行与模板

### 8.1 多行选择

发送编辑区支持选择多行。右键菜单中的规则操作会显示为“设置选中行规则”和“清除选中行规则”，并应用到全部所选行。

### 8.2 模块

模块用于组织一组命令，便于跳转和连续发送。模块由 `mode` 和 `modeend` 特殊命令定义。

### 8.3 模板导入与导出

- “导入模板”从模板文件载入命令、备注、启用状态和相关设置。
- “导出模板”保存当前命令配置。
- 导入前建议先导出现有配置作为备份。

## 9. 特殊命令

特殊命令写在发送编辑区中，由程序解释，不会全部作为普通字符串直接发送。

| 命令 | 示例 | 作用 |
| --- | --- | --- |
| `mode` | `mode:初始化` | 定义模块开始位置 |
| `modeend` | `modeend:0` | 定义模块结束位置 |
| `delay` | `delay:500` | 延时指定毫秒数 |
| `SendHex` | `SendHex:AA 55 01` | 按十六进制字节发送 |
| `BaudRate` | `BaudRate:115200` | 修改当前波特率 |
| `ComPort` | `ComPort:COM3` | 切换串口 |
| `SetEndlog` | `SetEndlog:\r\n` | 修改结尾标识符 |
| `SendMode` | `SendMode:初始化` | 执行指定模块 |
| `StopContinuous` | `StopContinuous:0` | 控制连续发送停止方式 |

### 9.1 模块结构

- `mode:name`：定义名为 `name` 的模块起点。
- `modeend:0`：定义当前模块结束位置。

### 9.2 延时与发送

- `delay:milliseconds`：暂停后续命令指定毫秒数。
- `SendHex:hex-bytes`：按十六进制发送字节，例如 `SendHex:AA 55 0D 0A`。

### 9.3 串口配置命令

- `BaudRate:value`：修改当前波特率。
- `ComPort:port`：切换到指定串口。
- `SetEndlog:value`：设置后续普通字符串命令的结尾标识符。

### 9.4 模块控制命令

- `SendMode:name`：触发指定模块的连续发送。
- `StopContinuous:0`：结束当前轮次，但保留循环发送状态。
- `StopContinuous:1`：停止连续发送，并关闭循环发送。

## 10. 常见问题

### 串口无法打开

- 检查串口是否被其他软件占用。
- 刷新串口列表并重新选择。
- 检查波特率、数据位、校验位和停止位。

### 替换按钮没有变色

- 确认已开启“替换发送”。
- 确认规则能在当前命令中查找到内容。
- 检查大小写、正则表达式和全字符匹配选项。
- 如果命令有独立规则，优先检查独立规则。

### 帮助文档没有更新

源码运行时，帮助窗口每次打开都会重新读取 `docs` 中的操作手册。EXE 中显示的是打包时包含的文档，需要重新打包才能更新。
