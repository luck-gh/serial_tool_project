# GHowe 串口调试助手 GUI 操作手册

适用版本：V1.2.5 Windows EXE

本文档面向直接使用可执行文件的用户，说明图形界面的日常操作、快捷键、查找与替换发送，以及发送编辑区支持的特殊命令。点击主窗口左下角 `?` 并选择“GUI 操作手册”，或按 `F1`，即可随时查看本文档。

## 1. 快速开始

1. 双击通用版或 GUI 专用版 EXE 打开程序。
2. 在左侧“基础设置”中选择串口和通信参数。
3. 点击“打开串口”，或按 `Ctrl+O`。
4. 在右侧发送编辑区新增或编辑命令。
5. 点击命令行的发送按钮发送单条命令。
6. 需要批量发送时，勾选命令行并使用“连续发送”。

正式发布的 EXE 文件名可能包含版本后缀，不影响图形界面操作。配置、命令或界面布局变化后会自动防抖保存；关闭窗口时还会执行最终保存。

## 2. 界面区域

- **基础设置**：串口、波特率、数据位、校验位和停止位。
- **远程控制**：在主控端和远程端之间共享串口数据与控制。
- **接收设置**：控制输出来源、保存接收数据和清空显示。
- **发送设置**：结尾标识符、发送显示颜色、替换发送和发送间隔。
- **发送编辑区**：编辑多条命令、备注、模块和独立替换规则。
- **模板相关**：导入或导出命令模板。
- **工具相关**：打开已启用的转换器和辅助工具。
- **帮助与配置**：`?` 打开 GUI/CLI 操作手册，“配置”用于管理程序和外部工具设置。

## 3. 快捷键

帮助类快捷键使用功能键，功能操作使用 `Ctrl+字母`。

| 快捷键 | 功能 |
| --- | --- |
| `F1` | 打开帮助窗口 |
| `Ctrl+O` | 打开或关闭串口 |
| `Ctrl+R` | 开始或停止连续发送 |
| `Ctrl+F` | 打开当前区域的查找栏 |
| `Ctrl+T` | 开启或关闭替换发送模式 |
| `Ctrl+H` | 将当前选中文本发送到转换工具 |
| `Enter` | 在发送命令编辑状态下发送当前行 |
| `Ctrl+Z` | 撤销编辑 |
| `Ctrl+Y` | 重做编辑 |
| `Ctrl+X` | 剪切 |
| `Ctrl+C` | 复制 |
| `Ctrl+V` | 粘贴 |
| `Ctrl+A` | 全选当前编辑内容 |

`Ctrl+F` 会根据当前焦点选择查找目标：焦点在接收区时查找接收文本，焦点在发送编辑区时查找发送命令。

## 4. 串口操作

### 4.1 打开与关闭

- 点击“打开串口”或按 `Ctrl+O` 建立连接。
- 连接成功后按钮显示“关闭串口”。
- 再次点击或按 `Ctrl+O` 关闭连接。
- 如果正在连续发送，关闭串口会先停止连续发送。

### 4.2 结尾标识符

“发送设置”中的结尾标识符会追加到普通字符串命令末尾。

| 选项 | 实际追加内容 |
| --- | --- |
| `None` | 不追加 |
| `\r\n` | 回车加换行 |
| `\r` | 回车 |
| `\n` | 换行 |

### 4.3 显示与保存接收区数据

“接收设置”中的“发送、接收、系统、错误”只控制接收区当前显示哪些来源。四类信息都会保留在本次运行的完整日志中，重新勾选后可以显示此前隐藏的信息。

“系统级别”可进一步筛选系统来源中的“常规、告警、信息、调试”；四个级别都可以按需要选择或取消。固件下载等特殊命令的日志会保留命令前缀，例如 `FirmwareDownload:`，便于在混合日志中定位来源。关闭“系统”来源时，所有系统级别都暂时隐藏；重新打开后仍按此前选择的级别显示。

点击“保存数据”后，可以独立选择本次需要保存的来源；勾选“系统”时还可选择要保存的系统级别。即使接收区当前没有显示“发送”或“系统”信息，只要保存时勾选，对应完整日志仍可写入文件。显示范围和保存范围会被记住，下次启动继续沿用。

“清空数据”会清除接收区和本次运行中已记录的完整日志。需要保留内容时，请先保存再清空。

## 5. 查找

### 5.1 接收区查找

1. 点击接收显示区。
2. 按 `Ctrl+F`。
3. 输入查找内容。
4. 按 `Enter` 查找下一个，按 `Shift+Enter` 查找上一个。

所有匹配内容都会以浅黄色背景高亮，当前匹配项使用稍深的黄色。查找不会把输入焦点强制切换到接收内容。

### 5.2 发送编辑区查找

1. 点击任意发送命令编辑区。
2. 按 `Ctrl+F`。
3. 点击“范围”，在弹窗中选择模块范围和搜索区域。
4. 搜索区域可选择“字符串”“备注”或“一起搜索”。
5. 模块范围支持多选；模块较多时可在列表中滚动浏览，也可直接选择“全部模块”。
6. 确认范围后，输入内容并连续按 `Enter` 浏览匹配项。


### 5.3 查找选项

- **区分大小写**：大小写必须完全相同。
- **正则表达式**：按正则语法解释查找内容。
- **全字符匹配**：只匹配完整单词或完整字符边界。
- **范围**：发送区可在弹窗中多选模块，并选择搜索字符串、备注或两者；模块列表支持滚动。

正则表达式无效时，查找栏会提示错误，不会修改命令内容。

## 6. 替换发送

替换发送只在数据发出的瞬间生成临时发送内容，发送编辑区中的原始字符串保持不变。

### 6.1 全局替换规则

1. 在“发送设置”中点击“全局规则...”。
2. 输入查找内容、替换内容；需要校验设备响应时再填写响应表达式。
3. 根据需要设置区分大小写、正则表达式和全字符匹配；需要校验时勾选“开启响应匹配”。
4. 勾选“替换发送”，或按 `Ctrl+T`。

默认全局规则会把 `write <通道> 0x<地址> 0x<值>` 转为 `read <通道> 0x<地址> 1`。点击“默认规则”会填入默认查找、替换和响应表达式，同时把当时的连续发送间隔复制为本规则的独立超时时间；点击后弹窗不会自动关闭。“开启响应匹配”默认关闭，需要使用时手动勾选。

点击“清除规则”只会清空弹窗内容，不会立即关闭；继续点击 OK 才会删除该规则，点击 Cancel 则保留原规则。清空后重新填写内容并点击 OK 会保存新规则。

### 6.2 命令行独立规则

1. 在发送编辑区选中一行或多行。
2. 右键打开菜单。
3. 选择“设置选中行规则”。
4. 输入所选命令行使用的替换规则。

拥有独立规则的命令行会显示规则标记。独立规则优先于全局规则。选择“清除选中行规则”可以移除所选行的独立规则。

### 6.3 是否可替换

程序使用与查找功能相同的匹配逻辑判断命令是否可替换：

- 能查找到匹配内容时，发送按钮进入可替换提示状态。
- 找不到匹配内容时，发送按钮保持普通状态。
- 连续发送中，能匹配的命令发送替换后内容；不能匹配的命令直接发送原始内容。

### 6.4 正则分组替换

开启正则表达式后，可以在查找内容中使用圆括号定义捕获组，并在替换内容中引用。

| 替换写法 | 含义 |
| --- | --- |
| `$1` | 第 1 个捕获组 |
| `${1}` | 第 1 个捕获组的明确写法 |
| `$2` | 第 2 个捕获组 |
| `$&` | 本次匹配到的完整文本 |
| `$$` | 字面量 `$` |

示例：

- 查找：`AT\+(\w+)=(\d+)`
- 替换：`CMD:$1,VALUE:$2`
- 原始命令：`AT+MODE=3`
- 实际发送：`CMD:MODE,VALUE:3`

### 6.5 响应表达式校验

响应表达式也是正则查找表达式。普通正则只负责在发送后的接收数据中查找响应；`$1`、`$2`、`${name}` 等引用上方“查找”表达式的捕获值，同时要求响应中的对应位置与原始值一致。

勾选“开启响应匹配”后，响应表达式输入框和右侧“设置...”按钮才可用。“设置...”弹窗用于配置独立超时、失败后继续或停止、循环策略及是否显示匹配系统错误；循环策略默认使用“失败后保持红色”，“显示匹配系统错误”默认关闭。

例如：

- 默认查找：`^write\s+(\d+)\s+(?:0x)?([0-9A-Fa-f]+)\s+(?:0x)?0*([0-9A-Fa-f]+)\s*$`
- 替换为：`read $1 0x$2 1`
- 默认响应表达式：`read [01] 0x\w* 1\W*\w*\s*=\s*0*$3\W`

默认响应表达式只校验写入值，并允许设备返回值带有额外前导零。如果需要同时校验通道、地址和值，可以使用：

`read $1 0x$2 1\r?\n$2\s*=\s*0*$3\W`

默认表达式中的 `[01]`、`\w*` 等普通正则只负责查找，只有 `$3` 与原始写入值比较。支持 `$1`、`${1}`、`${name}` 和 `$$`；引用不存在的捕获组时无法保存规则。

串口接收数据会按连续数据流处理：一条响应可以跨多个串口包，一个串口包也可以完成多条校验。同一段响应只会分配给一个待校验任务；存在冲突时优先分配给最早发送的任务。

- 校验通过：对应发送字符串单元格显示淡绿色。
- 校验失败或超时：对应单元格显示淡红色。开启“显示匹配系统错误”后，错误信息会同时显示替换后实际发送的字符串；如果收到完整响应但校验值不同，还会显示具体值差异，只有无法找到完整响应结构时才显示超时详情。
- 直接点击发送和未开启循环的连续发送：始终显示最近一次校验结果，后续通过可以覆盖红色。
- 循环策略“显示最近一次结果”：循环发送时，后续通过可以覆盖红色。
- 循环策略“失败后保持红色”：循环发送时，保持红色直到复位、修改命令或修改规则。
- 失败后可选择继续发送或停止连续发送。
- 统计栏中的“校验通过: n/x”只统计已经完成的校验。
- 点击“复位”会同时清除校验统计、等待中的校验和单元格状态颜色。

### 6.6 按钮颜色

- 替换发送模式下，可替换的单条发送按钮使用紫色背景和白色文字。
- “全局规则...”按钮使用紫色背景和白色文字。
- 替换模式下的连续发送按钮使用紫色背景和白色文字。
- 普通连续发送运行状态使用橙色提示。

## 7. 连续发送与循环发送

### 7.1 连续发送

1. 勾选需要执行的命令行。
2. 在“连续发送模块”中选择“全部”或指定模块。
3. 设置“连续发送间隔(ms)”。
4. 点击“连续发送”，或按 `Ctrl+R`。
5. 再次点击或按 `Ctrl+R` 停止。

连续发送会在一次发送单元内完成查找、替换判断和实际发送，不会另外修改命令内容。

### 7.2 循环发送

勾选“循环发送(ms)”后，一轮连续发送结束会等待设定间隔，再开始下一轮。

## 8. 命令行与模板

### 8.1 多行选择

发送编辑区支持选择多行。右键菜单中的规则操作会显示为“设置选中行规则”和“清除选中行规则”，并应用到全部所选行。

### 8.2 模块

模块用于组织一组命令，便于跳转和连续发送。模块由 `mode` 和 `modeend` 特殊命令定义。

### 8.3 模板导入与导出

- “导入模板”从模板文件载入命令、备注、启用状态和相关设置。
- “导出模板”保存当前命令配置。
- 导入前建议先导出现有配置作为备份。

## 9. 特殊命令

特殊命令写在发送编辑区中，由程序解释，不会全部作为普通字符串直接发送。

| 命令 | 示例 | 作用 |
| --- | --- | --- |
| `mode` | `mode:初始化` | 定义模块开始位置 |
| `modeend` | `modeend:0` | 定义模块结束位置 |
| `delay` | `delay:500` | 延时指定毫秒数 |
| `SendHex` | `SendHex:AA 55 01` | 按十六进制字节发送 |
| `BaudRate` | `BaudRate:115200` | 修改当前波特率 |
| `ComPort` | `ComPort:COM3` | 切换串口 |
| `SetEndlog` | `SetEndlog:\r\n` | 修改结尾标识符 |
| `SendMode` | `SendMode:初始化` | 执行指定模块 |
| `StopContinuous` | `StopContinuous:0` | 控制连续发送停止方式 |
| `FirmwareDownload` | `FirmwareDownload:D:\\firmware\\app.bin` | 调用固件下载工具下载文件 |

### 9.1 模块结构

- `mode:name`：定义名为 `name` 的模块起点。
- `modeend:0`：定义当前模块结束位置。

### 9.2 延时与发送

- `delay:milliseconds`：暂停后续命令指定毫秒数。
- `SendHex:hex-bytes`：按十六进制发送字节，例如 `SendHex:AA 55 0D 0A`。

### 9.3 串口配置命令

- `BaudRate:value`：修改当前波特率。
- `ComPort:port`：切换到指定串口。
- `SetEndlog:value`：设置后续普通字符串命令的结尾标识符。

### 9.4 模块控制命令

- `SendMode:name`：触发指定模块的连续发送。
- `StopContinuous:0`：结束当前轮次，但保留循环发送状态。
- `StopContinuous:1`：停止连续发送，并关闭循环发送。

### 9.5 固件下载命令

- `FirmwareDownload:`：使用“固件下载工具”配置中的默认固件文件。
- `FirmwareDownload:path`：使用指令参数指定的固件文件；路径包含空格时可使用双引号。
- 固件文件优先级为“指令参数 → 固件下载工具默认文件”。未指定有效文件时，下载不会启动。
- 下载的包大小、开始命令、CRC、ACK 和超时设置全部沿用固件下载工具配置。
- 下载开始前会释放串口助手占用的本地串口；下载完成后会恢复此前已打开的串口。下载失败或用户停止连续发送时，本轮连续发送停止。
- 该指令仅在“配置”中启用固件下载工具且工具可用时显示。如果右键菜单中没有该指令，请检查工具是否启用、默认固件和工具路径是否有效。
- 远程端模式和 CLI 模式暂不支持该指令。

## 10. 远程控制

远程控制用于让一台电脑操作另一台电脑连接的串口。连接串口设备的电脑作为“主控端”，发起操作的电脑作为“远程端”。两端应使用相同端口和密码，并确保网络与防火墙允许连接。

### 10.1 主控端

1. 在“远程控制”中选择“主控端”。
2. 设置监听端口和连接密码。
3. 根据需要先打开本机串口；也可以在远程端连接后再请求打开。
4. 点击“启用远程控制”，等待状态显示“监听中”或“已连接”。
5. 将主控端电脑的可访问地址、端口和密码提供给远程端用户。

### 10.2 远程端

1. 先关闭本机直接打开的串口。
2. 在“远程控制”中选择“远程端”。
3. 输入主控端地址、相同端口和密码。
4. 点击“启用远程控制”，等待状态显示“已连接”。
5. 在“基础设置”中选择主控端提供的串口参数，再点击“打开串口”。

远程控制启用后，关注“远程”状态文字和接收区中的系统、错误信息。连接异常时，先确认两端地址、端口、密码和防火墙设置，再重新启用远程控制。

## 11. 常见问题

### 串口无法打开

- 检查串口是否被其他软件占用。
- 刷新串口列表并重新选择。
- 检查波特率、数据位、校验位和停止位。

### 替换按钮没有变色

- 确认已开启“替换发送”。
- 确认规则能在当前命令中查找到内容。
- 检查大小写、正则表达式和全字符匹配选项。
- 如果命令有独立规则，优先检查独立规则。

### 连续发送中途停止

- 检查串口是否断开或被其他软件占用。
- 检查响应校验规则是否设置为“失败后停止”。
- 检查是否执行了 `StopContinuous:1`。
- 如果流程包含 `FirmwareDownload`，检查固件文件、下载参数和设备响应。

### “?”中的手册与当前功能不一致

操作手册与 EXE 版本对应。请先确认正在使用的程序版本，并使用同一版本附带的帮助内容；升级 EXE 后重新打开“?”窗口即可查看该版本手册。
