# 项目方向与后续计划

## 项目方向与边界

面向嵌入式设备调试，维护 GUI 串口工作台与 CLI 自动化入口；产品介绍和启动方式由 [README](../README.md) 维护，操作范围分别由 [GUI 手册](OPERATION_MANUAL_FOR_GUI.md) 和 [CLI 手册](OPERATION_MANUAL_FOR_CLI.md) 定义。

保持现有端到端使用路径，复用命令解析、配置管理和固件下载能力；模块职责及开发约束以 [开发说明](DEVELOPER_NOTES.md) 为准，远程回执、设备独占及结果未知的边界以 [远程协议](REMOTE_PROTOCOL.md) 为准。

当前优先收口已有CLI/终端/机器接口的质量及生命周期连接;Rust迁移和MCP暂不纳入当前范围.

## 当前阶段

当前发布状态、最新正式发布基线及历史验证状态统一见 [版本记录](VERSION_HISTORY.md)，不把暂存或中间提交作为新版本起点；未明确开启下一版本时不另建待发布章节。

## 已确认的后续计划

- 机器常驻接口的实际部署及设备验收由测试系统唯一操作者执行,源码/候选离线成功不替代实机验收. 完成实际目标连接、连续命令归属/失败停止及下载恢复后再关闭本项.

## 验证边界

当前能力证据与验证缺口统一见 [FEATURES.md](FEATURES.md)。离线检查与上板验收的区别及设备参数前提见 [远程协议](REMOTE_PROTOCOL.md)；这些前提不构成已授权的设备操作或新增计划。
