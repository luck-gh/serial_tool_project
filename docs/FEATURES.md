# 当前主要能力与验证证据

## 已验证能力

当前源码已有成功的离线验证记录，覆盖 GUI/CLI 模板导入导出、原始 RX 文件保存、同源系统信息及时间戳、远程连接并发关闭、GUI 显式配置路径和接收行展示避让；OK 与多行寄存器的跨块数值均有回归。展示仅在残缺接收行期间短暂延后日志，不保证协议多行响应整体不被日志分隔。验收日期、结果及证据边界统一见 [版本记录](VERSION_HISTORY.md#版本-126-2026-10-14)，不以源码或测试文件存在代替运行验证。

机器常驻接口已通过真实 CLI 子进程和隔离 GUI IPC 验证调用方 ID 贯穿、原始分片 RX、实际任务与采集窗口分离、显式关闭、连续同进程、失败停止、EOF 不取消且仍守原目标、断连/漂移、下载仅 owner 独占及恢复. GUI/CLI 失联和远程错误共享另有离线及候选验证. 机器子进程默认 cp936 时仍输出 UTF-8;CLI 依赖边界检查保持无 GUI 服务端及 QtWidgets/QtGui. 检查数量、日期及候选状态统一见版本记录,精确字段及验证入口见 CLI 手册和开发说明. 实际硬件与真实 GUI 操作仍待测试系统唯一操作者验收.

有界日志流显示、配置窗口中的独立日志页签、MB记录预算、独立收录来源/级别/时间戳及可选分块文件保存已通过源码离线检查. 覆盖显示筛选不改变收录、发送快捷入口四种基础状态恢复及重启、全量与时间戳独立、Unicode历史淘汰、跨批文件无重漏、慢盘/失败停存及另存、日志/工具草稿确认或取消、失败共同回滚、主界面保存状态和退出补写;入口为 `checks/log_stream_check.py`. Windows原生离屏截图确认主界面开关与日志/工具页签布局、时间戳位置、颜色和联动;隔离GUI持续输入确认文件完整且记录预算未超限,具体量级和验证边界见版本记录. 未完成整夜实机测试或新EXE验收.

这些记录对应当时的源码，不能覆盖后续源码变化；离线源码检查不证明真实串口、跨电脑链路、跨 Windows 用户桥接或 EXE 产物已经验收。

独立一次性CLI/常驻终端的新日志收录与后台归档已通过`checks/cli_log_check.py`及完整源码套件. 真实CLI子进程与隔离GUI IPC覆盖日志配置只读查询/校验、原子应用失败回滚、独立时间戳、发送OR与颜色、隐藏TX收录、尾部失败退出、部分写入与显式另存、慢盘/大事件预算、GUI实际状态/恢复完成回执、已有终端动态同步及故障后的本地恢复. 普通CLI不导入QtWidgets/QtGui或GUI配置schema,机器JSONL与原始RX保持独立. 当前进程内存批次不跨进程恢复;具体数量及未验证边界见版本记录.

一次性CLI已验证短写0/部分、写入超时/硬件异常及flush失败均停止后续模块并返回唯一unknown,尾读/close与日志补尾复合故障保留原未知信息. 机器stdout失效及stdout/stderr同时关闭均在stdin保持打开时非零退出,已受理GUI延迟任务仍按detach语义只执行一次,不伪造结果或自动重发. 证据来自`console_check.py`与`machine_session_check.py`的隔离故障注入及真实CLI/IPC,不代表真实硬件验收.
